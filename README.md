# Dungeon Adventure Game 🎮

A text-based adventure game built with Python OOP.

## Features
- Turn-based combat system
- Multiple enemy types
- Level up system
- Inventory management
- Experience points

## How to Play
```bash
python game.py
```

## Classes
- **Player**: Main character with health, attack, experience
- **Enemy**: Monsters with different stats
- **Game**: Game controller managing battles and menu
